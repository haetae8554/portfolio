## 구성

이 저장소는 본인이 무엇을 했는지 정리하는 연도별 활동 기록입니다. README는 최신 연도부터 배치하며, 각 연도 안에서 해커톤·개인 프로젝트·수업 팀 프로젝트·수업 과제·기초 실습을 구분합니다. 상세 설명은 `projects/`에 두고 연도별 항목에서 연결합니다.

프로젝트 코드는 각각의 저장소에 보관합니다. 비공개 과제·실습도 활동 주제를 기록할 수 있지만 코드·제출 파일은 공개 기록에 복사하지 않습니다. GitHub 프로필에는 이 저장소 링크를 넣거나 고정 저장소로 선택할 수 있습니다.

- 복지나침반은 2026 KW 해커톤 참여 기록, 모아는 2026년 개발 기록을 기준으로 분류합니다.

- 두 자료구조 과제와 Git 실습은 저장소 이름 및 2025년 개발 기록을 기준으로 분류합니다. 정확한 수행 월이나 학기는 임의로 추가하지 않습니다.
- 이후 다른 해에 개선한 내용은 해당 연도에도 연결하되, 상세 문서에서 원래 수행 시점과 후속 개선을 구분합니다.
